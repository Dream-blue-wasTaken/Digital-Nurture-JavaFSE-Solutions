# Hands-on Lab 2: Git Ignore Answers (2. Git-HOL_answers.md)

## Objective
Understand and implement `.gitignore` functionality to ignore unwanted log files and directories during commits.

---

## Step-by-Step Execution

1. **Verify Prerequisites:**
   Ensure you are in an active Git repository (`GitDemo`).

2. **Create Log File and Log Directory:**
   ```bash
   touch app.log
   mkdir logs
   touch logs/error.log
   ```

3. **Check Unstaged Status:**
   ```bash
   git status
   ```
   *Expected Output:*
   Shows `app.log` and `logs/` under untracked files.

4. **Create and Update `.gitignore` File:**
   ```bash
   echo "*.log" >> .gitignore
   echo "logs/" >> .gitignore
   ```

5. **Verify Ignored Status:**
   ```bash
   git status
   ```
   *Expected Output:*
   Only `.gitignore` appears under untracked files. Neither `app.log` nor `logs/` directory appear.

6. **Check Ignored Files explicitly:**
   ```bash
   git status --ignored
   ```

7. **Commit `.gitignore` file:**
   ```bash
   git add .gitignore
   git commit -m "Add .gitignore to ignore log files and directories"
   ```

8. **Verify Clean Repository State:**
   ```bash
   git status
   ```
   *Expected Output:* `nothing to commit, working tree clean`
