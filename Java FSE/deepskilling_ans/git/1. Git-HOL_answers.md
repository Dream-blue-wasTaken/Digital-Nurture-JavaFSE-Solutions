# Hands-on Lab 1: Git Configuration & Setup Answers (1. Git-HOL_answers.md)

## Objective
Learn and practice fundamental Git commands (`git init`, `git status`, `git add`, `git commit`, `git push`, `git pull`) and basic editor configuration.

---

## Step 1: Setup machine with Git Configuration

1. **Verify Git Installation:**
   Check if Git client is installed properly by opening Git Bash and running:
   ```bash
   git --version
   ```
   *Expected Output:* `git version 2.x.x.windows.x`

2. **Configure Global User Credentials:**
   Set global user name and email ID:
   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "your.email@example.com"
   ```

3. **Verify Global Configuration:**
   ```bash
   git config --global --list
   ```
   *Expected Output:*
   ```text
   user.name=Your Name
   user.email=your.email@example.com
   ```

---

## Step 2: Integrate Editor (Notepad++ / VS Code) as Default Editor

1. **Test Editor Execution from Git Bash:**
   ```bash
   notepad++
   ```

2. **Configure Editor in Git:**
   Configure Notepad++ (or default editor) as the core Git editor:
   ```bash
   git config --global core.editor "'C:/Program Files/Notepad++/notepad++.exe' -multiInst -nosession"
   ```

3. **Verify Editor Setting:**
   ```bash
   git config --global -e
   ```
   *(Opens editor displaying the global configuration file).*

---

## Step 3: Add a File to Source Code Repository

1. **Create and Initialize Project Directory:**
   ```bash
   mkdir GitDemo
   cd GitDemo
   git init
   ```
   *Expected Output:* `Initialized empty Git repository in .../GitDemo/.git/`

2. **Verify Hidden Files in Working Directory:**
   ```bash
   ls -la
   ```

3. **Create `welcome.txt` and Add Content:**
   ```bash
   echo "Welcome to Git Hands-on Lab 1" > welcome.txt
   ls
   cat welcome.txt
   ```

4. **Check Working Directory Status:**
   ```bash
   git status
   ```
   *Expected Output:* `Untracked files: welcome.txt`

5. **Stage and Commit File:**
   ```bash
   git add welcome.txt
   git commit -m "Initial commit: Added welcome.txt"
   ```

6. **Verify Repository Status:**
   ```bash
   git status
   ```
   *Expected Output:* `nothing to commit, working tree clean`

7. **Connect & Synchronize with Remote Repository:**
   ```bash
   git remote add origin https://github.com/your-username/GitDemo.git
   git pull origin master --allow-unrelated-histories
   git push -u origin master
   ```
