# Hands-on Lab 5: Clean Up and Remote Push Answers (5. Git-HOL_answers.md)

## Objective
Finalize local branch cleanup, synchronize local repository with remote tracking repository (`git pull`), and push final changes back to remote (`git push`).

---

## Step-by-Step Execution

1. **Verify Master is Clean:**
   ```bash
   git checkout master
   git status
   ```
   *Expected Output:* `nothing to commit, working tree clean`

2. **List Available Branches:**
   ```bash
   git branch -a
   ```
   *Expected Output:* Only `* master` should be listed locally.

3. **Pull Remote Repository Changes to Master:**
   ```bash
   git pull origin master
   ```
   *Expected Output:* `Already up to date.` or pull merge details.

4. **Push Completed Local Changes to Remote Repository:**
   ```bash
   git push origin master
   ```
   *Expected Output:* `Writing objects: 100% ... Total ... master -> master`

5. **Verify Remote Sync Status:**
   ```bash
   git status
   ```
   *Expected Output:* `Your branch is up to date with 'origin/master'.`
