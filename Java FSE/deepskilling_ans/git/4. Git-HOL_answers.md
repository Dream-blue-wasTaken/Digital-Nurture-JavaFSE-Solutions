# Hands-on Lab 4: Conflict Resolution Answers (4. Git-HOL_answers.md)

## Objective
Implement conflict resolution when multiple branches modify the same file concurrently, resolving merge conflicts with 3-way merge tools.

---

## Step-by-Step Execution

1. **Verify Master is Clean:**
   ```bash
   git checkout master
   git status
   ```

2. **Create Branch `GitWork` and Add Initial `hello.xml`:**
   ```bash
   git checkout -b GitWork
   echo "<note><to>User</to><message>Hello from GitWork branch</message></note>" > hello.xml
   git add hello.xml
   git commit -m "Add hello.xml on GitWork branch"
   ```

3. **Switch to `master` and Add Conflicting `hello.xml`:**
   ```bash
   git checkout master
   echo "<note><to>User</to><message>Hello from master branch</message></note>" > hello.xml
   git add hello.xml
   git commit -m "Add conflicting hello.xml on master branch"
   ```

4. **Observe Log Graph Across All Branches:**
   ```bash
   git log --oneline --graph --decorate --all
   ```

5. **Compare Differences via Diff / Visual Tool:**
   ```bash
   git diff master..GitWork
   ```

6. **Attempt to Merge `GitWork` into `master` (Triggers Conflict):**
   ```bash
   git merge GitWork
   ```
   *Expected Output:*
   `CONFLICT (add/add): Merge conflict in hello.xml`
   `Automatic merge failed; fix conflicts and then commit the result.`

7. **Inspect Conflict Markup in `hello.xml` or Launch 3-Way Merge Tool:**
   ```bash
   git mergetool
   ```
   *(Or edit `hello.xml` manually to retain desired content and remove conflict markers `<<<<<<<`, `=======`, `>>>>>>>`).*

8. **Commit Resolved Merge:**
   ```bash
   git add hello.xml
   git commit -m "Resolved merge conflict in hello.xml"
   ```

9. **Add Backup Files (`*.orig`) to `.gitignore` if Generated by Merge Tool:**
   ```bash
   echo "*.orig" >> .gitignore
   git add .gitignore
   git commit -m "Ignore mergetool backup files"
   ```

10. **Clean Up Branch and Verify Log:**
    ```bash
    git branch -d GitWork
    git log --oneline --graph --decorate
    ```
