# Hands-on Lab 3: Branching and Merging Answers (3. Git-HOL_answers.md)

## Objective
Learn branching strategies, creating feature branches, inspecting differences, merging back into trunk (`master`), and branch cleanup.

---

## Step-by-Step Execution

### Part 1: Branching

1. **Create Feature Branch `GitNewBranch`:**
   ```bash
   git branch GitNewBranch
   ```

2. **List All Local and Remote Branches:**
   ```bash
   git branch -a
   ```
   *Note:* The `*` indicates the active branch (e.g., `* master`).

3. **Switch to `GitNewBranch`:**
   ```bash
   git checkout GitNewBranch
   ```

4. **Make Modifications in `GitNewBranch`:**
   ```bash
   echo "Feature work in new branch" > feature.txt
   git add feature.txt
   git commit -m "Add feature.txt in GitNewBranch"
   ```

5. **Verify Branch Status:**
   ```bash
   git status
   ```
   *Expected Output:* `nothing to commit, working tree clean` on `GitNewBranch`.

---

### Part 2: Merging

1. **Switch Back to `master`:**
   ```bash
   git checkout master
   ```

2. **List Differences Between `master` and `GitNewBranch`:**
   ```bash
   git diff master..GitNewBranch
   ```

3. **Launch Visual Diff Tool (e.g. P4Merge / git difftool):**
   ```bash
   git difftool master..GitNewBranch
   ```

4. **Merge `GitNewBranch` into `master`:**
   ```bash
   git merge GitNewBranch
   ```

5. **Inspect Log History Graph:**
   ```bash
   git log --oneline --graph --decorate
   ```

6. **Delete Merged Branch:**
   ```bash
   git branch -d GitNewBranch
   ```

7. **Verify Final Branch List and Repository Status:**
   ```bash
   git branch
   git status
   ```
